## Clasificación rápida

### Becas estatales / públicas
- Fondo de Solidaridad (nacional, para UDELAR/UTU/UTEC)
- Bienestar Universitario UDELAR (8 tipos)
- Becas Butiá (educación media)
- INEFOP Bachilleres (bachillerato)
- ANII (posgrado e investigación)

### Becas de universidades privadas
- ORT Uruguay - Excelencia Académica (hasta 80%)
- UCU - Dámaso Antonio Larrañaga (50%-100% matrícula)
- UM - Becas por rendimiento (parciales o completas)

### Becas internacionales
- Programa Roberto Rocca (Techint - ingeniería)
- FUNIBER (posgrados)
- Erasmus+ (movilidad a Europa)

### Becas gremiales / específicas
- SMU (congresos médicos)
